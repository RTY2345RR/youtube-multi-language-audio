# Credits

## Demo voices: CMU ARCTIC

The demo in `examples/` clones two reference recordings from the CMU ARCTIC
speech databases (speakers `bdl`, male, and `slt`, female, utterance
`arctic_a0003`: "For the twentieth time that evening the two men shook hands."),
so the demo contains no real person's voice taken without consent.

## Voice engine

Speech is generated by the [Miragea](https://miragea.ai) voice-cloning engine.

## Prior art

[ThioJoe/Auto-Synced-Translated-Dubs](https://github.com/ThioJoe/Auto-Synced-Translated-Dubs)
pioneered subtitle-timed dubbing for YouTube. Its behaviour was studied; no code
was copied (it is AGPL-3.0, this project is MIT and written from scratch).
